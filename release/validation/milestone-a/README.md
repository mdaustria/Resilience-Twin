# Milestone A: local input-based engineering proof

Accepted for the bounded **exploratory model-cell demonstration** on 14 October 2026. `release/acceptance.json` pins fourteen distinct evidence artifacts by SHA-256. Recheck with `uv run python scripts/verify_release.py --milestone A`; this validates file confinement, hashes, the frozen arithmetic reference scores, both complete source/intake/extraction records, source-only exports, reviewed geography and separate sealed/run/paired export records. `--prepare` rebuilds the two source-specific summaries and manifest after all inputs and checks are reviewed; it rejects incoherent evidence.

The two original public PDFs are not committed. Their hashes and full physical-page counts are in the [intake record](../document-intake/full-source-intake.json). The [extraction verification](../extraction/verification.json) and [critical-fact adjudication](../extraction/adjudication.json) are separate for Quezon City (112 pages, six critical facts) and Guiguinto (191 pages, ten critical facts). The case-specific full-extraction records here link both. The plan's unresolved Guiguinto `3,987` versus `4,087` FAMILY total stays a gap; the proof does not convert either to people. The 2023-2025 applicability and proposed procurement are labeled.

Each case has a source-only gap HTML/PDF and a different evaluated HTML/PDF in [reports](../reports/). The source-only exports contain no measured outcomes. Evaluated exports name the pinned model-cell boundary, exclusions, OSM snapshot, reviewed connectors, source citations, hypothetical cohort/resources/water/date, normal and exact-edge closure results, and a paired pickup-water change. Run JSON records show the graph/scope hashes, four event and metric hashes, reviewed input seal, scenario outcomes and paired deltas. The QC proof covers only a Talayan-centered 100-person hypothetical cohort; the Guiguinto proof covers only a Poblacion-centered 100-person hypothetical cohort. Neither result estimates all residents of its jurisdiction.

The [reference scores](reference-scores.json) use the previously frozen synthetic fixture and zero tolerances. Resource feasibility/dispatch, population terminal accounting and a separate one-day post-arrival water quota reproduce all three hand arithmetic cases exactly. The [boundary/replay record](boundary-replay.json) names the 21 passing engine tests; the [sensitivity fixture](../sensitivity/tiny-expanded.json) includes one-factor and adverse cases under greedy and reference policies. The [routing review](routing-review.json) and [geography review](../geography/pilot-areas.json) pin both graphs and explicitly record assumptions. The [engineering discrepancies](engineering-discrepancies.json) include resolved implementation issues and open source/model limitations, with no unresolved critical arithmetic or conservation discrepancy.

This gate establishes deterministic, input-based engineering behavior on two public documents and small OSM model cells. It does not establish field predictive accuracy, facility access/operability, public deployment readiness, or whole-city/municipality performance. The frozen protocol's `reference_scoring: not_started` describes its pre-score freeze state; the separate dated score artifact records the subsequent check without changing the protocol or tolerances. Owner-isolated public upload and report delivery remain Phase 4/5 work.
