# Extraction validation record

Task 3.3 has separate, source-bound public-PDF extraction artifacts. `raw/`
contains exact provider response bytes; `batches/` records usage, citations,
coverage and validation issues. `adjudication.json` reviews critical facts for
each source separately, including manual recovery and rejected candidates.
`verification.json` is generated by `uv run python -m scripts.verify_extraction`;
the verifier checks every original physical page, raw hashes, saved replay,
per-document denominators and complete critical-item records without an AI call.

Provider-inspected coverage is not proof that every fact was found or correct.
Raw statements remain candidates. Source-only review and operational readiness
are separate; location, resource and scenario assumptions are handled later.
