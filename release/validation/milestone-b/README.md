Milestone B is **open**. `source-only-browser.json` records a passing, limited
browser stage for each exact supplied PDF: full-file intake, source-only review,
PDF gap export and original-byte preservation. `full_journey_verified: false` is
intentional. These records do not prove supplemented simulation, paired change,
accessibility, ownership lifecycle or recovery.

`scripts/verify_release.py --milestone B` requires separate checked journey,
accessibility, isolation/lifecycle and browser-check records for acceptance.
The final evidence index belongs in `release/acceptance.json` only after both
complete journeys and the named checks pass.
