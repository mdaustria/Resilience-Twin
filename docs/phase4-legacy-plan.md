## Phase 4: Private ownership and durable work — milestone B, backend

Replace the local proof adapters incrementally with Cloud Firestore and private Cloud Storage for Firebase artifacts (ADR-029). Keep all private data operations behind the API: server-side ownership checks and IAM replace SQL RLS; Firebase client Security Rules deny direct private-data access. Firestore transactions enforce bounded version/job/usage updates. Store large immutable graphs and event bundles in Storage; Python geospatial adapters replace planned PostGIS operations. Reuse the validated domain/engine contracts. Public exposure remains gated on Phase 6.
